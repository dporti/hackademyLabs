LOS 5 ERRORES QUE SUSPENDEN 0485
01
i <= v.length
El bucle se pasa una posición y salta ArrayIndexOutOfBounds.
02
s1 == s2
Comparar Strings con == en vez de equals().
03
static everywhere
Todo static para que compile, sin entender qué es un objeto.
04
catch vacío
Capturar la excepción y no hacer nada: el error desaparece, el fallo no.
05
referencias
Creer que asignar un objeto lo copia, cuando solo copia la referencia.
